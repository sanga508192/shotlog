# ทดสอบ ShotLog ในสนามจริง (1 รอบ)

ใช้มือถือเครื่องที่ออกรอบจริง จดผลสั้น ๆ แล้วส่งผ่าน **ฉัน → ตั้งค่า → ส่งความเห็นถึงผู้พัฒนา** (เปิด "ส่งรายงานข้อผิดพลาดอัตโนมัติ" ไว้ด้วย)

## ก่อนออกจากบ้าน (มี Wi-Fi)

- [ ] อัปเดตแอปเป็นรุ่นล่าสุด (แถบ "อัปเดต" ด้านบน หรือ ตั้งค่า → โหลดแอปรุ่นล่าสุดใหม่)
- [ ] หน้าเริ่มรอบของสนามที่จะไป → กด **⬇️ เก็บแผนที่สนามไว้ใช้ตอนไม่มีสัญญาณ** จนขึ้น ✓
- [ ] ชาร์จแบตเต็ม จดเปอร์เซ็นต์แบตตอนเริ่มรอบ: ____ %

## ระหว่างเล่น

- [ ] เปิด **📍 จับตำแหน่ง GPS ตอนบันทึก** และกดบันทึกขณะยืนที่ลูกทุกช็อต
- [ ] ทีออฟหลุมแรก: ไม้ที่แอปแนะนำตรงกับที่ตั้งใจใช้ไหม (ใช่ / ไม่ใช่)
- [ ] ช็อตที่ 2 หลังเดินไปถึงลูก: ระยะ "ถึงกรีน" ที่แอปบอก ต่างจากป้ายระยะ/เครื่องวัดกี่หลา: ____
- [ ] ใช้ปุ่ม **จบหลุมด้วยพัต** พร้อมเลือกระยะพัตแรก อย่างน้อย 9 หลุม
- [ ] ถ้ามีลูกลงน้ำ/OB: กดผลช็อต แล้วลอง **ปักจุดที่ลูกไป** บนแผนที่ (แตะได้ตรงไหม ช้าไหม)
- [ ] เปิดโหมดเครื่องบินชั่วคราว 1 หลุม: แผนที่หลุมยังขึ้นภาพไหม และจดช็อตได้ปกติไหม
- [ ] มีจุดไหนกดยาก ช้า หรืองง จดไว้: ____

## หลังจบรอบ

- [ ] แบตเหลือ ____ % (เล่นไป ____ ชั่วโมง)
- [ ] สกอร์การ์ดรวมตรงกับที่นับเองไหม และไม่มีกล่อง "สกอร์รวมยังไม่ครบ"
- [ ] หน้าพัฒนา → Strokes Gained ขึ้นตัวเลขไหม (ต้องมีหลุมที่ข้อมูลครบ 9 หลุมขึ้นไป)
- [ ] ส่งความเห็นจากในแอป พร้อมผลข้างบน
