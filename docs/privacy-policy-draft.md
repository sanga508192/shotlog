# นโยบายความเป็นส่วนตัว ShotLog (ร่าง)

> **สถานะ: ร่างสำหรับตรวจทาน ยังไม่ใช่ฉบับใช้งานจริง**
> ข้อความใน [วงเล็บเหลี่ยม] ต้องเติมก่อนเผยแพร่ และควรให้ผู้เชี่ยวชาญกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA) ตรวจทานก่อนใช้
> ร่างนี้เขียนให้ตรงกับการทำงานของแอปรุ่น 0.14 ถ้าแอปเปลี่ยนวิธีเก็บหรือส่งข้อมูล ต้องแก้นโยบายนี้ด้วย

ปรับปรุงล่าสุด: [วันที่]

## 1. ผู้ควบคุมข้อมูลส่วนบุคคล

[ชื่อบุคคลหรือนิติบุคคลผู้ให้บริการ] ("เรา") เป็นผู้ควบคุมข้อมูลส่วนบุคคลของแอป ShotLog
ติดต่อเรื่องข้อมูลส่วนบุคคล: [อีเมลสำหรับติดต่อ] · [ที่อยู่ (ถ้าเป็นนิติบุคคล)]

## 2. หลักการโดยย่อ

- ใช้แอปได้โดยไม่ต้องสมัคร ข้อมูลทั้งหมดเก็บในเครื่องของคุณ
- ข้อมูลขึ้นคลาวด์เฉพาะเมื่อคุณเข้าสู่ระบบเพื่อสำรอง/ซิงก์ หรือเลือกใช้ฟีเจอร์แชร์
- ไม่มีโฆษณา ไม่มีเครื่องมือติดตามพฤติกรรม (analytics) และไม่ขายข้อมูล
- ตำแหน่ง GPS ใช้คำนวณในเครื่อง ยกเว้นกรณีในข้อ 3.3

## 3. ข้อมูลที่เก็บและวัตถุประสงค์

### 3.1 ข้อมูลที่เก็บในเครื่องของคุณ (ไม่ส่งมาที่เรา หากไม่ได้เข้าสู่ระบบ)

รอบที่เล่น สกอร์ ข้อมูลรายช็อต ลูกโทษ ไม้กอล์ฟ บันทึกการซ้อม สนามที่เพิ่มเอง ค่าตั้งต่าง ๆ รวมถึงชื่อและแต้มต่อของเพื่อนที่คุณพิมพ์ใส่ หมุดสนามที่วางเอง และลิงก์คลิปที่เก็บไว้
ประวัติข้อผิดพลาดของแอปเก็บในเครื่องเท่านั้น คุณเลือกคัดลอกส่งให้เราเองได้เมื่อแจ้งปัญหา

### 3.2 เมื่อเข้าสู่ระบบเพื่อสำรองและซิงก์

| ข้อมูล | วัตถุประสงค์ | ฐานทางกฎหมาย |
|---|---|---|
| อีเมล | ยืนยันตัวตนด้วยรหัสทางอีเมล ติดต่อเรื่องบัญชี | สัญญา (ให้บริการตามที่ขอ) |
| ข้อมูลทั้งหมดในข้อ 3.1 (ยกเว้นประวัติข้อผิดพลาดและค่าการเข้าสู่ระบบ) | สำรองและซิงก์ข้ามเครื่อง | สัญญา |
| สถานะสมาชิก (ช่วงทดลอง แพ็กเกจ วันหมดอายุ) | ให้สิทธิ์ฟีเจอร์ที่เสียเงิน | สัญญา |

### 3.3 ตำแหน่ง (GPS)

- แผนที่หลุมใช้ตำแหน่งปัจจุบันคำนวณระยะในเครื่องเท่านั้น
- ถ้าคุณเปิด "จับตำแหน่ง GPS ตอนบันทึก" ตำแหน่งที่ตีแต่ละช็อตจะเก็บรวมกับข้อมูลช็อต และขึ้นคลาวด์ด้วยเมื่อคุณเข้าสู่ระบบ (ตามข้อ 3.2)
- หมุดแท่นที/กรีนที่คุณวางเองจะแชร์ให้ผู้เล่นอื่นเฉพาะเมื่อคุณเปิด "แชร์หมุด" (ข้อ 3.4)
- ปิดสิทธิ์ตำแหน่งได้ทุกเมื่อในการตั้งค่าของเครื่อง แอปยังใช้งานได้

### 3.4 ฟีเจอร์แชร์ที่คุณเลือกใช้เอง

- **แชร์หมุดสนาม:** ตำแหน่งหมุดแท่นที/กรีน/ขอบกรีนที่คุณวางเอง และข้อมูลว่าวางด้วย GPS หรือแตะบนแผนที่ ผู้ใช้อื่นเห็นเฉพาะค่ากลางรวมของหลายคน ไม่เห็นว่าใครวางและไม่เห็นเวลา ปิดแชร์เมื่อใด หมุดที่เคยแชร์จะถูกลบทันที (ฐาน: ความยินยอม)
- **สกอร์สด:** ชื่อผู้เล่นในก๊วน สกอร์รายหลุม และผลเกม ใครก็ตามที่มีลิงก์เปิดดูได้ ลิงก์หมดอายุ 2 วันหลังอัปเดตครั้งสุดท้าย หรือเมื่อคุณกดหยุดแชร์ โปรดแจ้งเพื่อนก่อนแชร์ชื่อของเขา (ฐาน: ความยินยอม/ประโยชน์โดยชอบด้วยกฎหมาย)
- **รูปสกอร์การ์ดและรูปก๊วน:** สร้างในเครื่อง ไม่ส่งมาที่เรา รูปก๊วนไม่ถูกเก็บในแอป

### 3.5 การชำระเงิน (เมื่อเปิดระบบสมาชิก)

การชำระเงินดำเนินการโดย Stripe เราไม่เห็นและไม่เก็บเลขบัตร เราเก็บเฉพาะรหัสลูกค้าและสถานะการสมัครที่ Stripe ส่งมา

## 4. บริการภายนอกที่แอปติดต่อ

| ผู้ให้บริการ | ใช้เมื่อ | ข้อมูลที่ผู้ให้บริการได้รับ |
|---|---|---|
| Supabase (เซิร์ฟเวอร์ภูมิภาคสิงคโปร์) | เข้าสู่ระบบ ซิงก์ แชร์ | ข้อมูลตามข้อ 3.2–3.4, IP |
| Esri (ArcGIS) | เปิดแผนที่หลุม | IP และพิกัดของภาพที่โหลด (บอกพื้นที่ที่กำลังดู) |
| YouTube / Google | ค้นหาหรือเปิดคลิปสอน | IP, คลิปที่ดู (ใช้โหมดความเป็นส่วนตัวของ YouTube สำหรับตัวเล่นในแอป) |
| jsDelivr | ใช้อ่านสกอร์การ์ดจากรูปครั้งแรก | IP (ดาวน์โหลดตัวอ่านตัวอักษร รูปไม่ถูกส่งออก) |
| GitHub Pages | เปิดแอป | IP และข้อมูลการเข้าถึงเว็บทั่วไป |
| [ผู้ให้บริการส่งอีเมล] | ส่งรหัสเข้าสู่ระบบ | อีเมล |
| Stripe | ชำระเงิน | ข้อมูลการชำระเงินที่คุณกรอกกับ Stripe |

## 5. การส่งข้อมูลไปต่างประเทศ

ผู้ให้บริการบางรายในข้อ 4 อยู่นอกประเทศไทย (เช่น สิงคโปร์ สหรัฐอเมริกา) เราเลือกผู้ให้บริการที่มีมาตรการคุ้มครองข้อมูลที่เหมาะสม [ระบุฐาน/มาตรการตาม PDPA มาตรา 28–29 หลังตรวจทาน]

## 6. ระยะเวลาเก็บ

- ข้อมูลในเครื่อง: จนกว่าคุณจะลบในแอปหรือลบแอป/ข้อมูลเบราว์เซอร์
- ข้อมูลบนคลาวด์: จนกว่าคุณจะลบบัญชี (ลบได้เองในแอป ข้อมูลรอบ หมุดที่แชร์ และสกอร์สดถูกลบทั้งหมด)
- สกอร์สด: 2 วันหลังอัปเดตครั้งสุดท้าย
- ข้อมูลการชำระเงินที่กฎหมายกำหนดให้เก็บ: ตามระยะที่กฎหมายกำหนด

## 7. สิทธิของคุณ

คุณมีสิทธิตาม พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ได้แก่ ขอเข้าถึงและขอสำเนา ขอรับหรือโอนข้อมูล คัดค้าน ขอให้ลบ ขอให้ระงับการใช้ ขอแก้ไขให้ถูกต้อง และถอนความยินยอม
ทำเองได้ในแอป: ส่งออกข้อมูล (JSON/CSV) แก้ไขข้อมูล ปิดการแชร์ ลบบัญชี
เรื่องอื่นติดต่อ [อีเมลสำหรับติดต่อ] เราจะตอบภายใน [30] วัน และคุณมีสิทธิร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล

## 8. ความปลอดภัย

รับส่งข้อมูลผ่าน HTTPS ฐานข้อมูลจำกัดให้แต่ละบัญชีอ่านได้เฉพาะข้อมูลของตัวเอง (Row Level Security) คีย์ที่มีสิทธิ์สูงไม่อยู่ในแอป

## 9. ผู้เยาว์

[ระบุนโยบายสำหรับผู้ใช้อายุต่ำกว่า 20 ปี / ต่ำกว่า 10 ปี ตามคำแนะนำของผู้ตรวจทาน]

## 10. การเปลี่ยนแปลงนโยบาย

หากมีการเปลี่ยนแปลงที่สำคัญ เราจะแจ้งในแอปก่อนมีผล
