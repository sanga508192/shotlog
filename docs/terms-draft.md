# ข้อตกลงการใช้งาน ShotLog (ร่าง)

> **สถานะ: ร่างสำหรับตรวจทาน ยังไม่ใช่ฉบับใช้งานจริง**
> ข้อความใน [วงเล็บเหลี่ยม] ต้องเติมก่อนเผยแพร่ และควรให้นักกฎหมายตรวจทาน โดยเฉพาะหัวข้อการชำระเงิน การคืนเงิน และการจำกัดความรับผิด

ปรับปรุงล่าสุด: [วันที่]

## 1. บริการ

ShotLog เป็นแอปจดสกอร์และข้อมูลรายช็อตของกอล์ฟ วิเคราะห์เพื่อวางแผนฝึกซ้อม และแสดงแผนที่หลุมพร้อมระยะ ให้บริการโดย [ชื่อผู้ให้บริการ]
- **ใช้ฟรี:** จดและวิเคราะห์ข้อมูลที่เก็บในเครื่อง
- **สมาชิก (ShotLog Plus):** สำรองและซิงก์บนคลาวด์ ใช้หลายเครื่อง และฟีเจอร์แชร์ เช่น สกอร์สด ตามแพ็กเกจที่แสดงในแอป

## 2. บัญชี

คุณเข้าสู่ระบบด้วยอีเมลและรหัสที่ส่งไปทางอีเมล โปรดรักษาการเข้าถึงอีเมลของคุณ คุณรับผิดชอบการใช้งานภายใต้บัญชีของคุณ

## 3. สมาชิกและการชำระเงิน

- ราคาและรอบการเรียกเก็บแสดงในแอปก่อนชำระ ชำระผ่าน Stripe
- แบบตัดบัตรรายเดือน/รายปี ต่ออายุอัตโนมัติจนกว่าจะยกเลิก ยกเลิกได้เองในแอป สิทธิ์ใช้ได้ถึงสิ้นรอบที่ชำระแล้ว
- แบบ PromptPay จ่ายล่วงหน้า 1 ปี ไม่ต่ออายุอัตโนมัติ
- ช่วงทดลองใช้ฟรี [30] วันสำหรับบัญชีใหม่
- การคืนเงิน: [ระบุนโยบาย เช่น ไม่คืนเงินสำหรับรอบที่เริ่มแล้ว ยกเว้นกรณีที่กฎหมายคุ้มครองผู้บริโภคกำหนด]
- หากสมาชิกสิ้นสุด ข้อมูลในเครื่องยังใช้ได้ตามปกติ ข้อมูลบนคลาวด์ [ระบุว่าจะเก็บไว้นานเท่าใด]

## 4. ความถูกต้องของข้อมูลในแอป

- หมุดแท่นที/กรีน โดยเฉพาะหมุดที่มีป้าย "ค่าประมาณ" หรือมาจากผู้เล่นอื่น อาจคลาดเคลื่อนได้ ระยะจาก GPS ขึ้นกับความแม่นยำของเครื่อง
- Strokes Gained งบสโตรก และแฮนดิแคปโดยประมาณ เป็นค่าประมาณเพื่อการฝึกซ้อม ไม่ใช่สถิติหรือแฮนดิแคปทางการ
- การใช้อุปกรณ์วัดระยะในการแข่งขันให้เป็นไปตามกติกาของรายการและสนาม ผู้ใช้เป็นผู้รับผิดชอบ

## 5. การใช้งานที่ไม่อนุญาต

- วางหรือแชร์หมุดที่รู้ว่าผิดโดยเจตนา
- ใช้สกอร์สดหรือช่องทางใดในแอปเผยแพร่เนื้อหาที่ผิดกฎหมายหรือละเมิดผู้อื่น
- พยายามเข้าถึงข้อมูลของผู้อื่น รบกวนระบบ หรือดึงข้อมูลจากบริการเป็นจำนวนมากโดยอัตโนมัติ

เราอาจระงับบัญชีที่ฝ่าฝืน

## 6. เนื้อหาของคุณ

ข้อมูลที่คุณจดเป็นของคุณ คุณส่งออกและลบได้ทุกเมื่อ เมื่อคุณเลือกแชร์หมุดสนาม คุณอนุญาตให้เรานำไปรวมเป็นค่ากลางแบบไม่ระบุตัวตนเพื่อแสดงให้ผู้ใช้อื่น จนกว่าคุณจะปิดการแชร์

## 7. บริการภายนอก

ภาพดาวเทียมจาก Esri และคลิปจาก YouTube เป็นของเจ้าของแต่ละราย และอยู่ภายใต้ข้อกำหนดของผู้ให้บริการนั้น
